about=Single-purpose, local-first QGIS plugin from Digital University Kerala for hyperspectral image processing. It drives an external C++/OpenMP/OpenCL engine to compute spectral indices (NDVI, NDWI, NDBI, SAVI, EVI, NDMI, MSAVI) from hyperspectral rasters, writes them as GeoTIFF or VRT layers, and loads the results straight into the QGIS canvas. All per-pixel math runs in the native engine to keep large scenes off the Python heap. The plugin ships binary-free: the engine is located at run time from a configured path, the system PATH, or built from the bundled hpc-engine source.
