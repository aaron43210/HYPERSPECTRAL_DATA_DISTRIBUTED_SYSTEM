about=Single-purpose, local-first QGIS plugin from Digital University Kerala for hyperspectral image processing. It drives an external C++/OpenMP/OpenCL engine to process hyperspectral rasters entirely on local hardware, writing results as GeoTIFF or VRT layers and loading them straight into the QGIS canvas. All per-pixel math runs in the native engine to keep large scenes off the Python heap. The plugin ships binary-free: the engine is located at run time from a configured path or the system PATH, or downloaded with one click from the project's GitHub Releases (or built from the hpc-engine source in the repository).
 .
 Three operations are selectable from one uncluttered dialog: (1) Spectral indices - NDVI, NDWI, NDBI, SAVI, EVI, NDMI and MSAVI; (2) PCA - principal-component dimensionality reduction producing false-colour PC composites (covariance or correlation matrix); (3) SAM - Spectral Angle Mapper reflectance-based target detection from a reference pixel picked on the map, with an optional detection mask and similarity band. Compute runs on all CPU cores with OpenMP (a full 224-band EnMAP scene in a few seconds on a laptop, memory bounded by thread count); an optional OpenCL GPU backend works on Apple, NVIDIA, Intel and AMD GPUs and falls back to the CPU automatically.
