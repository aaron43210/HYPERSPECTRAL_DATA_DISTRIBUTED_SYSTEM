about=HyperSpatial Sedona Analytics is a local-first QGIS plugin from Digital University Kerala for distributed, per-pixel spatial analytics over the spectral-index GeoTIFFs produced by the HyperSpatial processing engine. It runs bundled PySpark + Apache Sedona raster jobs (AOI filter, per-field spatial join, NDVI filter, raw-cube NDVI, and unsupervised K-Means land-cover clustering with Spark MLlib) directly on the per-tile GeoTIFFs via RS_FromGeoTiff, with zonal statistics reprojected into each raster's CRS. Spark runs as a background subprocess so the QGIS UI is never blocked; outputs are written as CSV directories. Data transfer stays GeoTIFF + CSV + WKT (no GeoParquet/pyarrow, which collides with the system GDAL). Requires a working Spark/Sedona environment (see the bundled spark-sedona/requirements.txt).
